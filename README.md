# My Kayal Website App

A Flask-based website for Kayal, featuring freight quotes and a clean web interface.

## ✨ Features

- 📊 Freight quote data display (JSON)
- 🌐 Responsive web pages
- 🔒 Secure environment variable handling
- 🚀 Production-ready with Gunicorn + Nginx

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Data**: JSON
- **Server**: Gunicorn + Nginx (Ubuntu)
- **Version Control**: Git + GitHub

## 📋 Requirements

- Python 3.8+
- pip
- Git
